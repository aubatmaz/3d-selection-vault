# Survey, disclosure and footer release report

31 August 2026. Existing architecture retained.

1. **Root cause:** the checked-out How it works section was a static heading, with no toggle handler or disclosure state. Therefore the specific third/fourth-toggle symptom could not be reproduced as described. Browser inspection did reproduce a page-load crash: shared bibliography code imported Citation.js's Node-only dependencies into the client (`node:util.promisify`). The parser was separated from browser-safe export code. No timeout or forced-render workaround was introduced.
2. **Fix files:** `components/detail-disclosure.tsx`, `components/vault-details.tsx`, `lib/bibtex-parser.ts`, `lib/bibliography.ts`, and the server import route. Technique identity keys reset the detail subtree; proper native button, aria-expanded and aria-controls drive the disclosure. Existing native details/summary were inspected; other static sections were left unchanged.
3. **Repeated interactions:** six alternating mouse clicks pass in the browser and DOM tests. DOM tests also pass double-click, Enter, Space, identity change and unmount/reopen. Browser dialog reopening and technique switching pass. Browser-injected keyboard actions did not activate the control; only DOM keyboard success is claimed.
4. **Footer:** global root-layout footer with brand, description, help, about and license links. It appears on catalogue, survey/graph surfaces, help, about and license routes.
5. **Counter:** moved out of headers into the footer; still real D1 totals, one anonymous browser-tab session per UTC day, not unique people. Rerender/dialog/filter changes do not record new entries. Existing analytics logic, privacy, deduplication and totals are preserved. Failure leaves footer content visible.
6. **License:** `/license` contains the exact repository MIT text and separates software licensing from metadata, external papers/figures and implementation-specific terms. `/about` provides a public project explanation. Footer navigation uses the existing framework Link component.
7. **Survey:** Argelaguet & Andujar, A survey of 3D object selection techniques for virtual environments (2013), DOI 10.1016/j.cag.2012.12.003. Publisher record: https://www.sciencedirect.com/science/article/pii/S0097849312001793. Evidence copy: https://www.cs.ucf.edu/courses/cap6121/spr15/readings/3Dselection.pdf. No paper text/figures are redistributed.
8. **Identified techniques:** 32 in the explicit extraction scope: 31 named Table 1 rows plus World-in-Miniature discussed in §4.3. This does not claim exhaustive coverage of every supporting design pattern or all 108 bibliography entries.
9. **Already existing:** 12 canonical techniques reused after comparing names, mechanisms and associated papers.

11. **Publications:** 17 new records; 12 existing source records reused. Three Crossref exact title/year matches were obtained across the source set; other unavailable/unmatched queries fall back to explicit survey-bibliography metadata. Unknown DOIs remain null.
12. **Duplicates avoided:** 12 technique duplications and 12 source-publication duplications avoided. Existing canonical aliases are not silently rewritten; alternate survey names are searchable evidence/open alias claims.
